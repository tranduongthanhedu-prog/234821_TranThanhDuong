# HE THONG QUAN LY SACH

## Thong tin sinh vien
- Ho ten: Tran Thanh Duong
- MSSV: 234821
- Mon hoc: Dien toan dam may

## Mo ta de tai
Xay dung he thong quan ly sach tren nen tang dam may.
Ung dung cho phep them, xem, sua va xoa sach.

## Cong nghe
- React
- Node.js, Express
- MongoDB Atlas
- GitHub
- Docker, Docker Hub
- Render

## Cau truc du an
- frontend/: Giao dien React
- backend/: API Node.js va Express

## Huong dan cai dat
1. Clone repository ve may.
2. Cai dat Node.js va cac thu vien.
3. Cau hinh ket noi MongoDB Atlas.
4. Chay frontend va backend.

Chi tiet lenh chay se duoc cap nhat sau khi hoan thanh ung dung.
